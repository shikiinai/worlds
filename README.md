# Worlds

Shiki's quartz repo (hacked together tbh, we'll see if it updates later). In the quartz directory,
[Update quartz](https://quartz.jzhao.xyz/upgrading) with
```bash
npx quartz update
```

[Build and preview](https://quartz.jzhao.xyz/build) with
```bash
npx quartz build --serve
```

[Sync notes](https://quartz.jzhao.xyz/authoring-content#syncing-your-content) with
```bash
npx quartz sync
```
